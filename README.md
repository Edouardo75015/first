Objectif
Savoir créer un lien cliquable permettant d'accéder à une page ou un autre site

Les notions à connaitre : 

(<a>) permet de créer un lien

(<href>) indique l'adresse de destination du lien

Voici Un exemple de code :  <a href="https://www.google.com">Aller sur Google</a>

Dans cet exemple là "Aller sur Google" est le texte cliquable. L'attribut href indique le lien mène vers Google

Erreur fréquente à éviter 

Ne pas oublier href ou son adresse : <a>Aller sur Google</a> 

Ce code permet pas de créer correctement un lien vers Google, Il faut écrire  <a href="https://www.google.com">Allerne sur Google</a> .
